# Changelog

## 1.0.0 — 2026-10-25

First packaged GitHub release for Apple Silicon Macs running macOS 14 or newer.

- Offline background removal with bundled BiRefNet segmentation and matting models.
- Drag-and-drop, file opening, and clipboard image import.
- Immediate import feedback and an early original-image preview during preparation.
- Original/Cutout comparison with graph-paper, white, and dark preview backgrounds.
- Pinch zoom, zoom controls, drag/scroll panning, and Fit (⌘0).
- Zoomed images extend behind the floating controls; Fit keeps the full image clear of them.
- Reversible cropping with transparent PNG export and clipboard copy.
- Cached mode results, processing cancellation, and retry.
- Consistent button sizing, full-area click targets, and mode guidance.

The app bundles its runtime and models. It is ad-hoc signed and not notarized.
